Guides, tools, templates and examples to build new civilizations, units, maps, adventures and rules with plain files, nothing to compile.

What you
can create.

01 Civilizations and unitsNew civilizations or variants of the game's own, units with their stats, specials and custom sprites.
    02 Abilities and itemsTroop and hero abilities, items, formations, buttons, icons and graphics.
      03 Rules and victoryVictory modes, lobby options, scripts, XML and INI patches, languages and keys.
        04 Random mapsRandom map types built from a PNG, neutral outposts and starting cities.
          05 Maps, adventures and audioScenarios, adventures and conquests with cutscenes, plus music, sounds and voices.

            Just files, nothing to compile.

            Only the tools need Node.js.

            What you
            need.

            Imperivm III HD installed from Steam, and Imperivm Resurrected in the game folder, next to gbr.exe. Without the mod, the game loads nothing you create. The badge above shows the minimum mod version this SDK version asks for.

            Node.js, for the tools and the validator. There is nothing to compile: a mod is a folder inside mods\ with a mod.json and the files it changes or adds, using the same paths the game uses.

            A text editor for XML, JSON and scripts, and an image editor if you want your own buttons, icons or sprites: they are converted from PNG. The SDK has no tool for drawing sprites.

            Some tools ask for the game's DATA folder. extract-data.js pulls it out of data.pak.

            Included
            examples.

            The zip has one finished mod per topic, and each guide points to its own: civilization-example (a Dacia), unit-example, unit-graphics-example, ability-example, item-example, formation-example, outpost-example, random-map-example, victory-example, options-example, patches-example, scripts-example, specialty-example, ai-tactic-example, custom-orders, custom-texts and french-language.

            They all pass the SDK's own validator, so they work as a known-good starting point.

            A template
            for each thing.

            A template is an empty mod with the folders the game reads, a valid mod.json and a README with the steps. Copy the one closest to what you want to make, rename it and put your files where the notes say.

              Start in three steps.

              01

              Copy a template

              Copy a template folder, such as scenario or units, into the game's mods folder.

              02

              Change it and validate it

              The validator checks your mod without opening the game and gives the file and line of each problem.

              03

              Enable it in the game

              In Additional content, enable the mod in your profile. Errors show up in Logs\imperivm\imperivm-mod.log.

              Read the getting started guide

              Tools.

              They need Node.js. Run them from the SDK folder (for example, node tools\validate-mod.js); each one explains its use when run without arguments.

              Reference and publishing

                Licenses and
                language.

                The tools and the example mods are MIT: you can copy and reuse them. The guides are CC BY-SA 4.0: if you copy or translate them, credit the source and share under the same license. Imperivm Resurrected, the mod, is a separate project under the GPL, and the GPL does not apply to the SDK.

                The guides are in English in the SDK, and in Spanish and Italian on this website. The tools and the examples are in English, and the tools print their messages in English. The website itself is in Spanish, English and Italian.

                Sharing it.

                Mods are published on GameBanana, and the manager's Browse content tab searches there. The publishing guide covers the nine categories, the tags and how to upload the zip.

                If your mod is on GameBanana, people who play online with you download it from there. If you don't upload it, the host can only send it to a player who doesn't have it if you set "redistributable": true in mod.json.
