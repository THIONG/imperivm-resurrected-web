01 Overview

Imperivm Resurrected is an unofficial mod for Imperivm III: Great Battles of Rome HD, the Steam version. It is a single file, winmm.dll, that the game loads at startup. It does not modify gbr.exe on disk and includes no game files: you need the original.

Mostly it changes how the game is drawn and how it connects, and it adds tools. It also fixes unexpected crashes and some gameplay bugs, so not everything behaves exactly as in the original.

  • Display. Resizable or borderless window, resolutions up to 2048x1536 and the Steam overlay.
  • Online. Rooms over Steam, with no port forwarding and no VPN.
  • Additional content. An in-game manager with profiles and a GameBanana catalog.

Project status. It has no connection to FX Interactive or Haemimont Games. Versions are 0.x and bugs are likely.

02 What it adds
Display and sound
Direct3D 11 instead of GDI, vsync, sharp, smooth or integer scaling, a resizable or borderless window, resolutions up to 2048x1536 and an extended view. The monitor does not change resolution. Audio runs on a modern engine and the game mutes in the background.
Multiplayer
A dedicated screen with a room list, chat, Steam friend invites and passwords. Everyone needs the same mod version and the same gameplay content; anything missing downloads from the host. If you drop, you can rejoin the game in progress, as long as the host allows it and you have not gone about 30 seconds without traffic. There are no ranked games or automatic matchmaking.
Spectator mode
You can watch a room in progress with a 30-second delay, with pause and 10-second jumps. Spectators need the mod too. There is no chat and you cannot switch player.
Additional content
Enable and disable packages, profiles, warnings about shared files and about values another package overrides, and a tab for searching GameBanana. Load order is automatic. It warns about conflicts between packages but does not resolve them.
Cheats and map
Ctrl+T opens a cheat panel (resources, healing, spawning troops and more). In a room, the host decides whether they are allowed with the “Allow cheats” option. The M key opens a zoom map with fog.
Convenience
Autosave with several slots, rebindable controls, adjustable scroll speed and a panel with FPS, CPU, memory and network.
Bug report
From the heart icon in the main menu, Create report builds a zip in Logs\imperivm\reports with the logs and system data, with your SteamID, IPs and Windows username redacted. It sends nothing: check the zip before sharing it.
Updates
At startup it checks GitHub. By default it only notifies; in imperivm-mod.ini you can make it install by itself or not check at all. Every update carries a signature the mod verifies. If the new version does not reach the menu in three startups, it goes back to the previous one.
For modders
An SDK to create civilizations, units, abilities, items, victory modes, random maps and more using only files (the tools need Node.js). Guides and examples in For modders.

Versions are 0.x and things can change between them. The notes for each one are on the releases page.

03 Installation

You need: Windows, Steam running and Imperivm III: Great Battles of Rome HD installed from Steam.

  1. Download the .zip of the latest version from the releases page. It contains winmm.dll and a mod folder.
  2. Close the game.
  3. In Steam, right-click the game, then Manage and Browse local files. This opens the folder that contains gbr.exe.
  4. Unzip it into that folder. Accept replacing if asked.
  5. Open the game from Steam.

Playing online. Everyone needs the same mod version and the same gameplay content. In the main menu, Multiplayer: one player creates the room and the others join.

Your settings are saved in imperivm-mod.ini, in the game folder. The zip doesn't include it, so installing a new version keeps them.

Windows warnings. winmm.dll has no Windows code signature, so SmartScreen or your antivirus may warn you. There is no installer.

Removing the mod. Delete winmm.dll from the game folder. The game goes back to the original.

If something fails, use Create report or look at the logs in Logs\imperivm, and report it on Discord or GitHub. More detail in the guide and FAQ.
