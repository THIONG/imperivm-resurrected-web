# Imperivm Resurrected – website

The website for **Imperivm Resurrected**, a community mod for *Imperivm III: Great Battles of Rome HD* on Steam. It's an unofficial fan project.

It's just HTML, CSS and a bit of vanilla JavaScript. No framework and no dependencies. One small Node script generates the English and Italian pages from the Spanish ones.

## What's in it

Everything lives in `src/`:

- `index.html`, `guide.html`, `sdk.html` and `credits.html` are the pages, written in Spanish. `en/` and `it/` hold the same pages in English and Italian, generated by `tools/build-languages.js`. Downloads link to the releases page on GitHub.
- `css/styles.css` holds all the styles.
- `js/` has the scripts: language and theme switching, the scroll animations, the donation dialog, and the download button that reads the latest GitHub release.
- `img/` has the images and logos.
- `sdk/` has the modding guides in Spanish, English and Italian, plus the SDK zip. These are generated, so don't edit them by hand.

The site is available in Spanish, English and Italian, each with its own address (`/`, `/en/`, `/it/`). On a first visit it suggests the language of your browser by redirecting; the language selector remembers your choice. Light or dark follows your system, and you can switch it from the header.

## Languages

The Spanish text lives in the HTML. The English and Italian text lives in the dictionaries in `src/js/i18n*.js`, under the same `data-i18n` keys. After changing any text, regenerate the other languages:

```
node tools/build-languages.js
```

`node tools/build-languages.js --check` only reports whether the generated pages are up to date.

## Run it locally

Any static server works:

```
npx http-server src
```

Then open `http://localhost:8080`.

## Deploying

The site is hosted on Vercel, which deploys the `src/` folder (see `vercel.json`) on every push to `main`. Pull requests get a preview deployment. All links are relative, so the site also works under a sub-path.
